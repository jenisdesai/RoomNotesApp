# Room Notes App

A simple and modern Notes application built using Kotlin and Android Jetpack components.

## Features

- Create Notes
- Edit Notes
- Delete Notes (Long Press)
- Auto Save on Back Press
- RecyclerView with ListAdapter & DiffUtil
- Room Database
- StateFlow
- MVVM Architecture
- Navigation Component
- Material Design 3

## Tech Stack

- Kotlin
- XML
- MVVM
- Room Database
- StateFlow
- Coroutines
- RecyclerView
- ViewBinding
- Navigation Component
- Material Design 3

## Architecture

```
Fragment
    ↓
ViewModel
    ↓
Repository
    ↓
DAO
    ↓
Room Database
```

## Learning Objectives

This project demonstrates:

- Room Database
- StateFlow
- MVVM
- Repository Pattern
- Navigation Component
- Coroutines
- RecyclerView Best Practices
